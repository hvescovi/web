# Tarefa
Você deverá criar um frontend em react/next.
Utilize o projeto que já está criado na pasta "front".

# Especificações

1) a variável de ambiente NEXT_PUBLIC_API_URL indica o backend a ser acessado
2) deverá existir uma tela de cadastro de pessoas, com as operações CRUD (create, retrieve, update e delete)
3) deverá existir uma tela de cadastro de celulares, com as operações CRUD
4) os detalhes de dados das pessoas e celulares estão na pasta "back", que contém o backend do sistema
5) este frontend será implantado no Vercel
